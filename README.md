# SC Lang

Редактор файлов локализации `.lang` для Stalcraft / Stalzone.

Текущая версия: 0.5.1.

> ⚠️ Предупреждение: программа написана с помощью нейросети. Перед использованием делайте резервную копию файлов локализации. Проверяйте результат после применения пресетов.

## Что это

SC Lang открывает `.lang`, показывает ключи и значения, ищет по тексту, сохраняет изменения и умеет применять готовые наборы замен названий.

## Требования

- Windows 10 или 11.
- .NET Framework 4.8 (входит в Windows 10/11).
- Закрытая игра при сохранении файла локализации.

## Быстрый старт

1. Запустить `...\sclang\sclang.exe`.
2. При первом запуске выбрать тему.
3. Нажать `Найти .lang` или `Обзор…`.
4. Выбрать `.lang`.
5. Нажать `Начать`.

При следующих запусках программа сама открывает последний файл.

## Главное окно

| Элемент | Действие |
|---|---|
| `Открыть…` | Выбрать `.lang` вручную |
| `Сохранить` | Записать изменения в текущий файл |
| `Сохранить как…` | Сохранить в новый файл |
| `Автонайти .lang` | Найти файлы в `%APPDATA%\EXBO`, `Program Files` |
| `Настройки` | Тема, резервные копии, предпросмотр, приветствие |
| `Пресет` | Выбрать встроенный или свой пресет |
| `Применить` | Применить пресет к текущему файлу |
| `Отменить пресет` | Вернуть значения до последнего пресета |
| `Свои…` | Создать, изменить, удалить свой пресет |
| `Поиск` | Фильтр по ключу и значению |

Ключи редактировать нельзя. Значения редактируются двойным кликом по ячейке.

## Поиск

- `Ctrl+F` — перейти в поле поиска.
- `Enter` или `F3` — следующий результат.
- `Shift+Enter` или `Shift+F3` — предыдущий результат.
- `Esc` — очистить поиск.

Поиск фильтрует строки по ключу и значению без учёта регистра.

## Сохранение

- Перед записью создаётся резервная копия `<файл>.bak`.
- Резервную копию можно отключить в настройках.
- Кодировка сохраняется: UTF-8 или Windows-1251.
- Переводы строк сохраняются.
- Если игра открыта, сохранение может не сработать. Закройте игру.

### Как применять

1. Открыть `.lang`.
2. Выбрать пресет.
3. Нажать `Применить`.
4. Проверить предпросмотр.
5. Нажать `Применить` в окне предпросмотра.
6. Сохранить файл.

Кнопка `Отменить пресет` возвращает значения до последнего применения.

## Свои пресеты

1. Нажать `Свои…`.
2. Нажать `Новый`.
3. Ввести название.
4. Выбрать готовое изменение в поле `Готовые` и нажать `Вставить`, либо заполнить вкладки вручную.
5. Нажать `Сохранить`.

Готовые примеры: `База «Рубежа» => База «Долга»`, `Обочина => Кордон`, и другие.

Пункты с пометкой `(все формы)` вставляют сразу все падежи: `Рубеж`, `Рубежа`, `Рубежу`, `Рубежем`, `Рубеже`.

Префиксы в квадратных скобках показывают источник готового изменения:

- `[Classic]` — замены из классики;
- `[Fun]` — замены из Fun;
- `[Classic exact]` / `[Fun exact]` — точные значения по ключам.

Группы с пометкой `(все формы)` вставляют сразу все падежи одного названия.

Поле слева от `Готовые` — фильтр по категории: `Все`, `Формы`, `Classic`, `Fun`, `Classic exact`, `Fun exact`.

Файлы лежат в `custom_presets\<имя>.preset`.

Предустановленные:

- `Мой_пресет.preset`
- `Шаблон_локаций.preset`
- `.dev.preset` — от разработчика: все названия локаций, аномалий, мутантов и артефактов (classic и fun).

Формат:

```
name=Мой пресет
[rules]
Было => Стало
[exact]
ключ=значение
```

Поддерживаются:

- `Дублировать` — копия пресета;
- `Изменить` — правка;
- `Удалить` — удаление файла.

## Свои правила в presets.txt

`presets.txt` рядом с `sclang.exe`.

Замены по тексту:

```
[classic]
Было => Стало

[fun]
Было => Стало
```

Правила `[fun]` применяются вместе с `[classic]`. Регистр важен. Более длинные правила срабатывают первыми.

Исключение:

```
Барьер => БульБуль || ЭГ-1 «Барьер»
```

Если значение содержит текст после `||`, правило к нему не применяется.

Точные значения по ключам:

```
[classic.exact]
checkpoints.dungeon_base_duty_lesta.control_point=База «Долга»

[fun.exact]
map.location.id.north_forge.name=Кухня-11
```

Точные значения применяются после замен. `Fun` берёт `classic.exact`, затем `fun.exact`.

## Решение проблем

### Файл не найден

Нажать `Автонайти .lang` или `Открыть…` и выбрать файл вручную.

### Не сохраняется

- Закрыть игру.
- Проверить права на папку.
- Запустить программу от имени администратора, если файл защищён.

### Сломались названия

1. Закрыть программу.
2. Вернуть `<файл>.bak`.
3. Или применить `Отменить пресет` до сохранения.

### Кракозябры

Файл должен быть UTF-8 или Windows-1251. Программа определяет кодировку автоматически. Если кодировка неизвестна, сохранить копию файла и открыть её вручную.

## Сборка

Нужен .NET Framework 4.x.

```
build.bat
```

Сборка использует `csc.exe` из Windows и `/codepage:65001` для кириллицы.

## Ограничения

- Пресеты меняют значения, не ключи.
- Пресеты применяются ко всем подходящим значениям файла.
- Пользовательские пресеты не синхронизируются между компьютерами.
- Файлы `.lang` могут быть большими, полная загрузка занимает несколько секунд.
